このサイトはゼロから作りました。テンプレートやCMS、サイトビルダーは使っておらず、イントロ、夜空、3Dハブ、ポートフォリオの各セクションはすべて自分で書いたコードです。ポートフォリオそのものを自分の一番のフロントエンド作品にしたかったので、このサイト自体がデモになっています。

## 技術スタック

- **React 18 + TypeScript**。**Vite**でバンドルし、React Routerを使ったシングルページアプリケーションとして構成
- 3Dシーンには**React Three Fiber**と**Drei**を介して**Three.js**を使用
- プロシージャルな背景には**Canvas 2D API**
- トランジションには**Framer Motion**、スタイリングには**SCSS**（セクションごとに1つのスタイルシート）
- **i18next**で英語・オランダ語・フランス語・日本語を実行時に切り替え
- テストには**Vitest**と**React Testing Library**、リントとフォーマットには**Oxlint**と**Prettier**
- **GitHub Actions**で、プッシュとプルリクエストのたびにリント、型チェック、フォーマットチェック、テスト、本番ビルドを実行
- ホスティングは**Netlify**で、独自ドメインのvictoriaghoos.comで公開

## イントロ

サイトを開くと、短い動画とタイプライター風に表示される挨拶から始まります。タイピングが終わるとCSSのオーバーレイアニメーションでメインページに切り替わります。イントロはボタンかEscキーでスキップできます。`sessionStorage`にフラグを保存しているので、イントロが表示されるのは1回の訪問につき1度だけです。`prefers-reduced-motion`が有効な場合は、動画の代わりに静止画を表示し、数秒でイントロを終了します。イントロを抜けるすべての経路にフェイルセーフのタイマーを用意しているので、アニメーションのイベントが発火しなくてもページが止まることはありません。

## 夜空

メインページの背景は、毎フレームcanvasにゼロから描画しています。

- **星雲。** フラクタルなパーリンノイズ（fBm、4オクターブ）をカラーランプに対応させています。ピクセルごと・フレームごとにノイズを計算すると重すぎるので、半分の解像度のオフスクリーンcanvasに一度だけ焼き込み、そのテクスチャを画面上でゆっくり漂わせています。
- **星。** サイズ・明るさ・パララックスの異なる3つの奥行きレイヤーに加え、独自の密な星の分布を持つ傾いた「銀河の帯」があります。星の色は本物の夜空に近づけるよう重み付けしていて、ほとんどが白か青白く、ときどき暖色の星が混ざります。
- **その他の演出。** 2枚のオーロラ、ランダムな流れ星、ビネット、そして軽量なブルーム処理です。ブルームは、フレームを3分の1サイズのcanvasにコピーしてぼかし、元の画像に重ねることで実現しています。
- **衝撃波。** 何もない場所をクリックすると衝撃波が広がります。波面の近くにある星は押し出され、減衰する速度でばねのように元の位置へ戻ります。

ループは30fpsに制限していて、セクションが画面外に出るとすぐに完全に停止します。

## 3Dナビゲーションハブ

デスクトップでは、ナビゲーションがWebGLのシーンになっています。5枚のパネルが、中央にある私のアバターのホログラムの周りを回ります。

- **回転。** リングはドラッグして回せます。前半分をつかむか後ろ半分をつかむかでドラッグの向きが反転するので、パネルは常にカーソルに追従します。最初の回転はフレームレートに依存しない係数で減速するため、60Hzでも144Hzでも同じ感覚になります。
- **ホバーで動画。** パネルにホバーすると、アイコンがループ再生の動画テクスチャに切り替わります。動画はホバーするまで読み込まず、テクスチャも実際に表示されている間だけ更新します。
- **ラベル。** 毎フレーム、各ラベルからホログラムの平面に向けてレイキャストを行い、パネルがホログラムの裏側に回るとラベルが隠れるようにしています。
- **星座。** 各パネルにホバーすると、パーティクルで描かれた星座が浮かび上がります。猫、本、花、カメラ、ヘッドセットの5つです。これらは小さなNodeスクリプトで作りました。Threeの`SVGLoader`でSVGを読み込み、パスに沿って点をサンプリングし、JSONに書き出しています。シーンでは、加算ブレンディングを使った1つの`THREE.Points`オブジェクトとして描画しています。

タッチデバイスや小さな画面では、3Dハブの代わりにシンプルなメニューグリッドを表示します。親指で3Dのリングを回すより、ボタンをタップするほうがずっと使いやすいからです。

## セクション

ハブの下にある各セクションはそれぞれ異なる雰囲気ですが、同じ夜空を共有しているので、サイト全体に統一感があります。

- **About。** 軌道リングに囲まれた、浮遊する「ホログラム」のアバター。
- **Skills。** 花びらが舞い落ちる桜のシーン。
- **Projects。** ローファイの音楽プレーヤー風のカードと、アニメーションするオーディオビジュアライザー。
- **Resume。** ページをめくって読めるフリップブック。
- **Contact。** WebGLで描画した雲。

きらめく星空の背景はすべて、自作のカスタムフック`useCanvasAnimationLoop`で動かしています。このフックは、デバイスピクセル比、リサイズ、画面外でループを一時停止する`IntersectionObserver`、そして`prefers-reduced-motion`に対応しています。`prefers-reduced-motion`が有効な場合は、アニメーションの代わりに静止した1フレームだけを描画します。

## パフォーマンス

アニメーションの多いページはすぐに重くなります。私のサイトも実際にそうなりました。改善のために行ったことの一部です。

- **Viteへの移行。** Create React AppからViteに移行したことで、開発サーバーのコールドスタートが30〜60秒から0.5秒未満になりました。
- **点群。** 星座のデータは当初55.2MBのJSONでした。ダウンサンプリング用のスクリプトで、見た目を変えずに1.7MBまで削減しました。
- **アセット。** スクリーンショットをWebPに圧縮し、Google Fontsをセルフホストの`@fontsource`パッケージに置き換え、3Dの環境マップと雲のテクスチャもセルフホストにしました。
- **遅延読み込み。** すべてのセクションをコード分割して遅延読み込みし、パネルの動画とBGMには`preload="none"`を指定しています。
- **一時停止。** WebGLのシーンは画面外に出ると`frameloop="never"`に切り替わり、canvasのループも同じように一時停止します。
- **キャッシュ。** ハッシュ付きのビルドアセットは、immutableのキャッシュヘッダー付きで配信しています。

これらすべてを合わせて、デスクトップのLighthouseスコアは25から85に上がりました。

## アクセシビリティ

ページ上で動く要素が多いため、`prefers-reduced-motion`はイントロ、canvasのループ、桜の花びら、浮遊エフェクトなど、あらゆる場所で尊重しています。操作要素はARIAラベル付きの本物のボタンで、キーボードでも操作できます。BGMは自分で再生ボタンを押したときだけ流れ、勝手に再生されることはありません。

## ホスティングとドメイン

victoriaghoos.comはNamecheapで購入し、Netlifyに向けています。Netlifyが本番ビルドのホスティングとHTTPSを担当しています。シングルページアプリケーションなので、すべてのルートを`index.html`に送るリダイレクトルールを1つ設定しています。そのため、このページのようなリンクを直接開いても正しく表示されます。
